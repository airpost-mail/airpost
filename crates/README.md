Rust library crates, all GPL-3.0-only (see the root LICENSE.md and NOTICE.md). The engine crates (tern-core, tern-store, tern-imap, ...) are used by apps/engine only; tern-wire holds the wire types shared by apps/engine and apps/backend, and depends on no engine crate. tern-ipc (serde only) is the engine socket protocol and its blocking client, for the engine, its tests and the CLI.
