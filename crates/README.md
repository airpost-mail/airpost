Rust library crates, all GPL-3.0-only (see the root LICENSE.md and NOTICE.md). The ms-* engine crates (ms-core, ms-store, ms-imap, ...) are used by apps/engine only; ms-wire holds the wire types shared by apps/engine and apps/backend, and depends on no engine crate. ms-ipc (serde only) is the engine socket protocol and its blocking client, for the engine, its tests and the CLI.
